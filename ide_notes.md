# Git в VS Code

Удобные возможности VS Code для работы с Git:

1. 1. В панели Source Control удобно видеть все изменённые файлы.
2. Можно быстро просматривать различия между версиями файлов.
3. Легко отслеживать историю изменений и коммитов.

Что удобнее делать в терминале:

- Команды git branch, git log и более сложные операции удобнее выполнять через терминал.
